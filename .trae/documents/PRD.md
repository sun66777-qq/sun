# 数据采集技术实战项目 | 课程作业 - 产品需求文档

## 1. 产品概述

- **项目名称**：数据采集技术实战项目展示网站
- **项目类型**：单页静态网站（Next.js 14 App Router）
- **核心用途**：展示10个行业级真实数据采集项目实战案例，供数据采集技术课程作业使用
- **目标用户**：数据采集技术课程学生、教师

## 2. 核心功能

### 2.1 功能模块

1. **顶部导航栏**
   - 课程名称展示："数据采集技术实战项目 | 课程作业"
   - 暗黑/明亮模式切换按钮

2. **项目卡片网格**
   - 响应式4列→3列→1列布局
   - 10个行业级数据采集项目展示
   - 每个项目包含：行业名称、技术栈、难度分级、核心功能描述、真实可运行代码片段

3. **项目详情卡片**
   - 悬停动效（Y轴位移+阴影增强）
   - 难度标签颜色编码（初级=绿色/中级=黄色/高级=红色）
   - 可复制的代码块（语法高亮）

4. **页脚**
   - MIT License 版权声明
   - 作者：李猫

### 2.2 页面结构

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 导航栏 | 课程名称 + 主题切换 |
| 首页 | 项目网格 | 10个项目卡片展示 |
| 首页 | 页脚 | 版权信息 |

## 3. 项目内容（10个真实行业级案例）

### 项目1：金融舆情监控系统
- **行业**：金融
- **技术栈**：Python + Scrapy-Redis + MongoDB + Redis
- **难度**：高级
- **功能**：采集新浪财经、东方财富等财经新闻，实时监控市场舆情
- **代码片段**：包含User-Agent轮换、IP代理池、请求频率控制

### 项目2：医疗文献采集系统
- **行业**：医疗
- **技术栈**：Python + Selenium + PubMed API + MySQL
- **难度**：高级
- **功能**：自动采集PubMed医学文献，支持DOI和摘要提取
- **代码片段**：包含API调用、登录验证、增量采集逻辑

### 项目3：电商价格追踪平台
- **行业**：电商
- **技术栈**：Node.js + Puppeteer + Express + Redis
- **难度**：中级
- **功能**：追踪京东、淘宝商品价格波动，设置价格提醒
- **代码片段**：包含动态渲染页面处理、Cookie管理、价格解析

### 项目4：房产数据采集分析
- **行业**：房地产
- **技术栈**：Python + Scrapy + Splash + Elasticsearch
- **难度**：中级
- **功能**：采集链家、安居客房源数据，分析房价趋势
- **代码片段**：包含Splash Lua脚本、分布式爬虫架构

### 项目5：招聘数据聚合平台
- **行业**：人力资源
- **技术栈**：Node.js + Cheerio + PostgreSQL + GraphQL
- **难度**：初级
- **功能**：聚合Boss直聘、猎聘网招聘信息，统一格式输出
- **代码片段**：包含列表页解析、详情页抓取、数据清洗

### 项目6：法律文书采集系统
- **行业**：法律
- **技术栈**：Python + Playwright + PDFParser + SQLite
- **难度**：高级
- **功能**：采集裁判文书网、法律法规数据库
- **代码片段**：包含JavaScript渲染处理、PDF解析、编码处理

### 项目7：高校导师研究领域采集
- **行业**：教育
- **技术栈**：Python + Requests + BeautifulSoup + Neo4j
- **难度**：中级
- **功能**：采集各高校导师信息，构建研究领域知识图谱
- **代码片段**：包含登录态维护、验证码识别、图谱数据建模

### 项目8：餐饮点评数据采集
- **行业**：餐饮
- **技术栈**：Node.js + Appium + MongoDB + Vue
- **难度**：中级
- **功能**：移动端APP数据采集，大众点评商铺评论分析
- **代码片段**：包含APP协议分析、签名算法、设备指纹

### 项目9：交通流量实时采集
- **行业**：交通
- **技术栈**：Python + Kafka + Redis + Grafana
- **难度**：高级
- **功能**：采集城市道路摄像头数据，分析交通流量
- **代码片段**：包含WebSocket推送接收、实时数据处理、异常检测

### 项目10：天气数据历史存档
- **行业**：气象
- **技术栈**：Python + WeatherAPI + InfluxDB + Telegraf
- **难度**：初级
- **功能**：定时采集多城市天气数据，构建历史数据库
- **代码片段**：包含定时任务、API调用、数据存储

## 4. 用户界面设计

### 4.1 设计风格
- **整体风格**：专业级企业展示风格，深色/浅色双主题
- **配色方案**：
  - 浅色主题：背景#F8FAFC，卡片#FFFFFF，主色#3B82F6
  - 深色主题：背景#0F172A，卡片#1E293B，主色#60A5FA
  - 难度颜色：初级#22C55E，中级#EAB308，高级#EF4444
- **字体**：Noto Sans SC（中文）+ JetBrains Mono（代码）
- **动效**：卡片悬停上浮8px + 阴影增强，transition 300ms ease

### 4.2 响应式断点
- 桌面端：≥1024px，4列网格
- 平板端：768px-1023px，3列网格
- 手机端：<768px，1列网格

## 5. 技术架构

### 5.1 技术选型
- **框架**：Next.js 14 (App Router)
- **样式**：Tailwind CSS
- **代码高亮**：Prism.js / highlight.js
- **图标**：Lucide React

### 5.2 目录结构
```
/app

  /layout.tsx      # 布局组件
  /globals.css     # 全局样式
/components
  /Header.tsx      # 导航栏
  /ProjectCard.tsx # 项目卡片
  /Footer.tsx      # 页脚
  /ThemeToggle.tsx # 主题切换
  /CodeBlock.tsx   # 代码块组件
/data
  /projects.ts     # 项目数据
```

## 6. 特别要求

### 6.1 代码片段要求
- 每个项目代码必须包含反爬策略实现
- 代码注释需标注课程作业要求说明
- 代码必须可直接运行，无占位符

### 6.2 部署要求
- 构建完成后输出 Vercel 部署命令
- 支持 `vercel --prod` 一键部署
